### fix(paypal): credit a settlement only when it matches the order recorded at checkout (fleet-chezmoi#2052)

Checkout now records each PayPal order (rail, order id, tenant, amount) in `topup_orders` (migration 0025) before the buyer is sent to pay, and refuses the checkout when that write fails. The webhook credits a settlement only when its order id, tenant and amount match that record, and credits the recorded tenant. An approved order that is not recorded, or is recorded for another tenant, is not captured. A mismatch answers 200 `applied:false` and logs `paypal.settlement_unmatched` at error level for an operator to reconcile. An unreadable order table answers 503 so PayPal retries. Deploy order: apply migration 0025 before this Worker serves. An order created before the migration is not recorded and does not credit automatically; the operator credit path covers it.
