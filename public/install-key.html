The click path

  1. Open your RunPod key settings and create a new API key.
  2. Choose Restricted.
  3. Set api.runpod.io/graphql to None. This is the part that matters: it is what stops this key from touching the rest of your account.
  4. Set api.runpod.ai to Restricted, then give Read/Write to the four endpoints listed above, and nothing else.
  5. Create it, and paste it below.

We check this key before we keep it. We try your four endpoints with it, and we try an account-level call that should fail. If it turns out to be more powerful than it needs to be, we tell you and we do not store it.
